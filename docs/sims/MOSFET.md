## 0. 方針

### 0.1 ねらい
- 「MOSFET はゲートの電圧で電流をオン・オフする部品」という**結論を、原子から積み上げて納得できる**こと。
- 公式を覚えさせるのではなく、**電荷 → 電場 → キャリアの動き**の因果を、目で見て手で動かして確かめられること。
- 数値はすべて一つのモデルから出す(画面の数字・3D の動き・グラフが食い違わない)。

### 0.2 対象
- 高校物理(電荷・電場・電位)を一通り習った人 〜 大学初年。電子工作で MOSFET を使っている人。
- 量子力学やバンド理論を前提にしない。エネルギーバンド図は「発展」として任意で見られるようにする(5 章)。

### 0.3 全体を貫く一本の筋(ストーリーライン)

```
原子は＋と−が釣り合って中性
  └▶ 不純物を入れても「結晶全体」は中性のまま。ただし「動ける電荷」と「動けないイオン」に分かれる
       └▶ 動ける電荷が去った場所では、動けないイオンだけが残って中性が崩れる
            └▶ 正味の電荷があれば、そこには必ず電場がある  ← 空乏層の本質
                 └▶ 電場がキャリアを押し流す(ドリフト)。拡散と釣り合って止まる(PN 接合)
                      └▶ ゲートの電圧で、表面に電場をつくってキャリアを集めたり追い払ったりできる(MOS)
                           └▶ 集めた電子が通り道になる → MOSFET
```

**空乏層の説明の軸は「キャリアがいない」ではなく「電場がある」こと。** キャリアがいないのは原因側(動ける電荷が去った)で、MOSFET や PN 接合の振る舞いを決めているのはそこに生じた電場である。全章でこの言い方に統一する。

### 3 章 原子は中性

- **ねらい**: 物質はふだん＋と−が釣り合っていて、外から見ると電気を帯びていない。
- **見せるもの**: シリコン原子のボーア模型(核「+14」、電子 2・8・4 の殻)。外側の 4 個(価電子)を強調。「この模型は簡略化した絵で、実際の電子は雲のように広がっている」と注記。
- **やってみよう**: 原子を **シリコン → リン(P, 15) → ホウ素(B, 5)** と切り替え、どれも「陽子の数 = 電子の数」であることを確かめる。電子を 1 個つまんで引きはがすと、残った原子が＋のイオンになるのを見る(イオン化)。
- **計器**: 陽子 +14 / 電子 −14 / 合計 0。引きはがすと「この原子 +1」「はがした電子 −1」「全部の合計 0」。
- **モデル**: 数え上げのみ。
- **誤解しやすい点**: 「電子を失った原子」と「電子」を別々に数えれば合計はいつも 0。電荷は消えたり生まれたりしない(電荷の保存)。

### 4 章 シリコンと不純物

- **ねらい**: 不純物を入れても**結晶全体は中性のまま**。ただし電荷が「動けるもの」と「動けないもの」に分かれる。これが後の章の土台。
- **見せるもの**:
  1. シリコンの結晶(2 次元の格子図で十分。4 本の手で隣と結合)。
  2. 室温では熱でまれに結合が切れ、電子と正孔が対でできる(真性。実際は 10¹² 個に 1 個以下とごくまれ、と数値で示す)。
  3. リンを 1 個入れる → 5 個目の電子が余り、室温でほぼ必ず離れて自由電子に。リンは動けない＋イオンとして格子に残る。
  4. ホウ素を 1 個入れる → 手が 1 本足りず、隣から電子を 1 個もらう → ホウ素は動けない−イオン、隣に正孔ができ、その正孔が動き回る。
- **やってみよう**: 格子にリンやホウ素をドラッグで置く。画面上の枠(範囲)を動かし、「枠の中の電荷の合計」を見る。**結晶全体の枠では常に 0**。小さな枠でイオンだけを囲むと＋や−になる。
- **計器**: 枠の中の合計電荷、自由電子の数、正孔の数、イオンの数。結晶全体の合計(常に 0)。
- **誤解しやすい点**:
  - **「ドープすると帯電する」は誤り。** n 型でも p 型でも、結晶全体は中性。
  - n 型の自由電子は「余分な電子」ではなく、リン原子がもともと持っていた電子。
  - 正孔は粒子が入っているわけではなく「電子の空席」。空席が移っていくので、＋の粒子が動くように見える。

#### 4 章の追加: 少数キャリアはなぜ激減するか(n·p = n_i²)
- **ねらい**: p 型では電子が「少し減る」のではなく、**桁違いに減る**。この驚きが、8 章で「p 型の表面に電子を集める(反転)」のがどれほど大きな変化かを実感させる。
- **見せるもの**: 純粋なシリコン、p 型、n 型の 3 つの箱を並べ、電子と正孔の濃さを**対数の棒グラフ**で表示する(3D の粒では桁の差を表せないため)。
  - 純粋: n = p = 10¹⁰ cm⁻³
  - p 型(N_A = 10¹⁶): p ≈ 10¹⁶、n ≈ 10⁴ cm⁻³(1 µm³ に 1 億分の 1 個)
- **しくみ(言葉で)**: 電子と正孔は熱で対になって生まれ、出会うと消える。正孔が多いところでは、生まれた電子がすぐ正孔に出会って消えるので、電子はほとんど残らない。生まれる速さと消える速さが釣り合うと、n × p が一定(= n_i²)になる。
- **やってみよう**: ドープ量のスライダーを動かし、多数キャリアが 10 倍になると少数キャリアが 10 分の 1 になることを見る。積 n × p の計器が一定のままであることを確かめる。
- **計器**: n、p、n × p(常に n_i² = 10²⁰ cm⁻⁶)、比 p / n。
- **モデル**: p = N_A、n = n_i² / N_A(完全イオン化、300 K)。
- **誤解しやすい点**: 「少数キャリア = 少しいる」ではなく、多数キャリアの 10¹² 分の 1 といった極端な差。それでも 0 ではないので、PN 接合の逆方向にわずかな電流(漏れ電流)が流れる。

### 5 章 押されて動く、広がって動く

- **ねらい**: キャリアが動く理由は 2 つ。**電場に押される(ドリフト)** と **濃いところから広がる(拡散)**。PN 接合はこの 2 つの綱引き。
- **見せるもの**: n 型の板。左右に電極。
  - 場面 A(ドリフト): 電圧をかけると電場の矢印が現れ、電子が電場と**逆向き**に流れる。電流の向きは電場の向き。
  - 場面 B(拡散): 片側に電子をまとめて置くと、電場がなくても熱運動で広がっていく。
- **やってみよう**: A で電圧スライダーを動かし、電子の平均の速さが電場に比例することを見る。B で電子の塊を置いて広がる様子を見る。
- **計器**: 電場の強さ、電子の平均速度、電流。
- **モデル**: ドリフト速度 v = μE(移動度 μ はシリコンの電子で約 1400 cm²/V·s、正孔は約 450)。拡散はランダムウォーク。
- **発展(切替)**: 電位を「坂」で表示。電子は坂を上るように動く(電子は負電荷なので電位の高い方へ)。バンド図はこの坂を電子の目で見たもの、と導入だけする。
- **フェルミ準位(切替表示「水位」)**: 電子がどこまで詰まっているかを示す「水位」の線。n 型では高く、p 型では低い。電圧をかけていないときは、どこでも水位が同じ高さになる(水が水平になるのと同じ)。6 章・7 章で使う。
- **誤解しやすい点**: 電子の動く向き ≠ 電流の向き。拡散は力ではなく「ばらばらに動いた結果の偏り」。

### 6 章 PN 接合と電場(本書の中心)

- **ねらい**: 空乏層とは「キャリアがいない層」である以上に、**取り残されたイオンの電荷がつくる電場がある層**。その電場が拡散を押し返して釣り合っている。
- **見せるもの**(時間の流れとして再生できる):
  1. くっつける前: 左に p 型、右に n 型。どちらも中性(4 章の計器で確認)。
  2. くっつけた瞬間: 濃度差で電子は p 側へ、正孔は n 側へ拡散し、境目で出会って消える(再結合)。
  3. **取り残されたイオンが現れる**: n 側の境目に＋イオン、p 側に−イオン。そこだけ中性が崩れる。
  4. **電場が生まれる**: ＋イオンの層から−イオンの層へ向かう電場の矢印が現れ、境目で最も強い。
  5. 釣り合い: 電場が電子を n 側へ、正孔を p 側へ押し戻す(ドリフト)。拡散と押し戻しが釣り合って、空乏層の幅が決まる。
- **やってみよう**:
  - 「試し電荷を置こう」: 空乏層の中に電子を 1 個置くと、電場で n 側へ一気に運ばれる。空乏層の外(中性の領域)に置くと、ほとんど押されない。→ **電場があるのは空乏層の中だけ**、を体で確かめる。
  - p 側と n 側の不純物の濃さをスライダーで変える。薄い側に空乏層が深く広がり、両側の電荷の量は常に等しい(＋の数 = −の数)ことを見る。
- **3D の下に並べるグラフ**(縦に 3 段、x 軸を 3D の断面とそろえる):
  1. 電荷の分布 ρ(x)(＋の箱と−の箱)
  2. **電場 E(x)**(三角形。電荷を左から足し合わせたもの)
  3. 電位 V(x)(段差 = 内蔵電位)
  - 「電荷 → 電場 → 電位」の順に、上の段を積み上げると下の段になる関係を矢印で示す。
- **計器**: 内蔵電位 V_bi、空乏層の幅 W(n 側 x_n と p 側 x_p)、最大電場 E_max、n 側と p 側の電荷の量(常に等しい)。
- **モデル**(1 次元・階段接合・空乏近似、300 K):
  - V_bi = (kT/q)·ln(N_A·N_D / n_i²)、kT/q = 0.0259 V、n_i = 1.0×10¹⁰ cm⁻³
  - W = √( 2ε_Si(V_bi − V)/q · (1/N_A + 1/N_D) )、ε_Si = 11.7ε₀
  - x_n·N_D = x_p·N_A(両側の電荷が等しい)
  - E_max = q·N_D·x_n / ε_Si
  - 例: N_A = N_D = 10¹⁶ cm⁻³ で V_bi ≈ 0.72 V、W ≈ 0.43 µm、E_max ≈ 3×10⁴ V/cm(= 3 V/µm)。この数値を初期値として表示し、実装時に計算結果と照合する。
- **誤解しやすい点**:
  - 空乏層にもキャリアは**ゼロではなく、非常に少ない**(空乏近似)。
  - 内蔵電位は電圧計では測れない(つないだ導線との接触部にも段差ができて打ち消される)。電池のように電流を取り出せるわけではない。
  - 電場の矢印は＋イオン側(n)から−イオン側(p)へ。電子はこの電場で n 側へ押される。
- **発展(フェルミ準位)**: 「水位」表示を ON にすると、くっつける前は n 側の水位が高く、くっつけた後は全体が同じ高さにそろう。そろえるために坂(内蔵電位)ができた、と見られる。水位が水平なので、電子の流れは差し引き 0 になる。内蔵電位が電圧計で測れない理由も「水位に差がないから」と説明できる。

### 7 章 外から電圧をかける

- **ねらい**: 外から電圧をかけると、空乏層の電場と幅が変わる。逆バイアスでは電場が強くなって広がり、順バイアスでは弱まって拡散が勝つ。
- **見せるもの**: 6 章の接合に電池をつなぐ。スライダーで −5 V(逆)〜 +0.8 V(順)。
- **やってみよう**: 逆バイアスで空乏層が広がり、最大電場が強まるのを見る。順バイアスで 0.6 V あたりから電流が急に増えるのを見る。
- **計器**: 印加電圧、W、E_max、電流(ダイオードの式 I = I_s(e^{V/V_T} − 1) で順方向のみ表示)。
- **発展**: 逆バイアスを強めて E_max が約 3×10⁵ V/cm に近づくと降伏(電子が加速されて次々と電子をはじき出す)。この章では「強すぎる電場は壊れる原因になる」と注記するにとどめ、13 章の耐圧につなぐ。
- **MOSFET へのつなぎ**: 「MOSFET のソースとドレインも、基板との間に PN 接合をつくっている。ふだんは逆バイアスなので、基板には電流が流れない」。
- **発展(フェルミ準位)**: 電圧をかけると、両側の水位に差ができる。その差がかけた電圧そのもの。
- 逆方向のわずかな漏れ電流は、4 章の「少数キャリアは 0 ではない」から来ていることを示す。

### 8 章 ゲートはコンデンサ

- **ねらい**: ゲート・酸化膜・p 型基板は、間に絶縁体をはさんだ**コンデンサ**。ゲートに電荷を置くと、基板の表面に反対の電荷が集まる(または追い払われる)。電荷の受け渡しは**電場**を通じて行われ、電流は流れない。
- **見せるもの**: ソースとドレインのない MOS 構造(ゲート・酸化膜・p 型基板・裏面電極)。V_GS は −3 V〜+5 V。
  - **蓄積**(V_GS < 0): 表面に正孔が集まる。
  - **空乏**(0 < V_GS < V_th): 正孔が追い払われ、−イオンが残る。空乏層の電場が表面から奥へ向かう。
  - **反転**(V_GS > V_th): 表面に電子が集まって、表面だけ n 型のようになる。空乏層の幅はここで止まり、それ以上の電荷は電子の層が受け持つ。
- **やってみよう**: V_GS を負から正へ動かし、3 つの状態を順に見る。**ゲートの＋の数と、半導体側の−(イオン + 電子)の数がいつも等しい**ことを計器で確かめる。酸化膜の厚さを変えて、しきい値が変わることを見る。
- **計器**: ゲート上の電荷、半導体側の電荷(内訳: −イオン / 電子 / 正孔)、表面電位、状態(蓄積 / 空乏 / 反転)、酸化膜中の電場。
- **グラフ**: 表面からの深さに対する電荷・電場・電位(6 章と同じ 3 段グラフ)。反転すると電場の三角形の上に、薄い電子層による段差が乗る。
- **モデル**(1 次元 MOS、空乏近似):
  - 空乏層の電荷 Q_d = q·N_A·W、W = √(2ε_Si·ψ_s / (q·N_A))
  - しきい値: ψ_s = 2φ_F、φ_F = (kT/q)·ln(N_A/n_i)。表面の電子の濃さ n_s = (n_i²/N_A)·e^{ψ_s/V_T} が、ψ_s = 2φ_F でちょうど N_A(元の正孔の濃さ)に追いつく。4 章の n·p = n_i² を使って計器に表示する(表面の電子の濃さが 10⁴ → 10¹⁶ cm⁻³ と 12 桁変わる)
  - V_th = V_FB + 2φ_F + √(2qε_Si·N_A·2φ_F) / C_ox、C_ox = ε_ox/t_ox(ε_ox = 3.9ε₀)
  - フラットバンド電圧 V_FB は定数として扱い、既存章の V_th = 2.0 V と合うようにパラメータを選ぶ(パワー MOSFET 相当)。選んだ値は画面に明記する。
  - 発展: V_FB はゲート材料と半導体の仕事関数の差、酸化膜中の電荷で決まる。製造のばらつきで V_th がずれる理由として、14 章のデータシート(V_GS(th) が 2〜4 V のように幅を持つ)につなぐ。
- **誤解しやすい点**:
  - しきい値は「スイッチが入る点」ではなく、表面の電子が十分に増えた目安。その下でも電子はわずかにいる(→ 12 章)。
  - 電子はゲートから来たのではない(酸化膜は通れない)。反転層の電子は、ソース・ドレインがあればそこから、なければ熱でゆっくり生まれる。

### 9 章 通り道をつくる(既存 III を改修)

- 変更点:
  - 「電場を表示」トグルを追加。ゲートから基板へ向かう電場(酸化膜の中で強く、空乏層で弱まっていく)を表示。
  - ソース・ドレインと基板の PN 接合にも空乏層と電場を表示(7 章とつなぐ)。
  - 説明文を「電場で正孔が押し下げられ、表面に電子が引き寄せられる」に統一。

### 10 章 流れと頭打ち(既存 IV を改修)

- 変更点:
  - 横方向の電場(ソース → ドレイン)を表示。チャネル内は弱く、**ピンチオフ点からドレインまでの短い区間に強い電場が集中**する様子を表示。
  - 「ピンチオフ = 電流が止まる」ではないことを明記。ピンチオフ点まで来た電子は、強い電場でドレインへ運ばれる。
  - I_D–V_GS(伝達特性)のグラフを切替で追加。

### 11 章 基板の電圧(既存 V)

- 変更点: 「電場を表示」トグル。V_SB を上げると基板側の電場が強まり、空乏層の電荷が増える関係を表示。8 章の式と同じ V_th の式で計算していることを明記。

### 12 章 しきい値の下と、ちょっとした誤差(発展)

- サブスレッショルド電流: V_GS < V_th でも I_D は指数関数的に変化する(約 60〜100 mV で 1 桁)。グラフを対数軸に切り替えて見せる。
- チャネル長変調: 飽和領域でも、ピンチオフ点がソース側へ少し動くので電流がわずかに増える。
- 温度: 温度を上げると V_th が下がり、移動度が下がる。結果として大電流側では電流が減る。
- 速度飽和・短チャネル効果: チャネルがとても短いと、電場が強すぎて電子の速さが頭打ちになり、二乗則から外れる。LSI の微細な MOSFET の話として紹介にとどめる。
- 既存の二乗則モデルに λ(チャネル長変調)とサブスレッショルドの指数部をつなげたモデルに置き換える(切替式。既定は単純モデル)。

### 13 章 実物の MOSFET(推奨)

- 縦型パワー MOSFET の断面(ソース・ゲートが上、ドレインが裏面。電流は縦に流れる)。v0.1 の注記「実物は縦型」をここで回収する。
- **ボディダイオード**: ソースと基板(ボディ)がつながっているため、基板とドレインの PN 接合がダイオードとして残る。回路図記号のダイオードの意味。
- **耐圧**: ドレイン側の厚い低濃度層の空乏層が、高い電圧(電場)を受け止める。7 章の降伏とつなぐ。
- オン抵抗と発熱(I²R)。

### 14 章 回路で使う(v0.5 で追加)

- **ねらい**: 物理で理解したことを、実際の回路でつまずく点に結びつける。1 章の机の上の回路に戻って実験する。
- **場面 A: 浮いたゲートとプルダウン抵抗**
  - ゲートの線を外す(浮かせる)と、ゲートに残った電荷で MOSFET はオンのまま、または指を近づけるなどのノイズでふらつく。ゲートは電流ではなく電荷(コンデンサ、8 章)で動いているから。
  - ゲートと GND の間に抵抗(例: 10 kΩ)をつなぐと、電荷が抜けて確実にオフになる。
  - 予想: 「ゲートの線を外すと LED はどうなる？」
- **場面 B: ロジックレベル**
  - マイコンの 3.3 V で、V_th が 2〜4 V の MOSFET を駆動するとどうなるか。V_th を超えても十分にオンにならず、オン抵抗が大きいまま発熱する。
  - データシートの R_DS(on) は「V_GS = 10 V のとき」のように条件付きで書かれていることを示す。「ロジックレベル」と書かれた部品は 4.5 V や 2.5 V での値が保証されている。
  - V_th のばらつきの範囲(最小〜最大)を設定して、最悪の場合でも点くかを確かめる。
- **場面 C: ゲート容量とスイッチング**
  - ゲートはコンデンサなので、オン・オフのたびに充電・放電の電流が一瞬流れる。ゲート抵抗を大きくするとスイッチが遅くなり、その間の発熱(スイッチング損失)が増える様子をオシロ風の波形で見せる。
  - 1 章の「ゲートにほとんど電流が流れない」は止まっているとき。切り替える瞬間には流れる。
- **場面 D: モーターをつなぐ**
  - 誘導性負荷をオフにした瞬間、電流を流し続けようとして高い電圧が出る。フライバックダイオードで逃がす。ボディダイオードとの違い。
- **場面 E: ゲートを壊さないために**
  - 酸化膜はとても薄いので、最大 V_GS(例: ±20 V)を超えたり静電気が入ったりすると絶縁が破れる。酸化膜の中の電場の強さを計器で示す(8 章の計算を再利用)。
- **データシートの読み方(まとめ)**: V_GS(th)、R_DS(on) とその条件、Q_g、最大 V_DS・V_GS・I_D、安全動作領域(SOA)を、架空の部品の 1 ページで読み解く(実在の型番は使わない)。
- **ハイサイドとローサイド(発展)**: ソースが GND にないと、ゲートをソースより高くしなければならず駆動が難しい。11 章の基板バイアスとも関係する。
- **モデル**: 1 章の LED 回路(二乗則)にゲート容量 C_iss とゲート抵抗、プルダウン抵抗を加えた過渡計算。V_th はばらつきの範囲で変えられるようにする。

### 15 章 なかまと比べる(発展)

- **p チャネル MOSFET**: n 型基板にホウ素の p⁺ ソース・ドレイン。ゲートを**下げる**と正孔のチャネルができる。
- **CMOS インバータ**: n と p を組み合わせると、入力が高いと出力が低い。片方が必ずオフなので、止まっているときに電流がほぼ流れない。
- **エンハンスメント型とデプレッション型**: V_GS = 0 でオフ(この教材で扱ってきた型)か、はじめからチャネルがあってオンか。
- **バイポーラトランジスタ(BJT)との違い**: BJT はベースに電流を流して制御する。MOSFET はゲートの電場で制御するので、止まっているときにゲート電流がいらない。大きな集積回路で MOSFET が主流になった理由。

### 16 章 確かめよう(総まとめ)

- 部ごとの確認問題(各 3〜4 問)を集めた総まとめ。各問に「その章へ戻る」リンク。
- 2.1 の「誤解の診断」と同じ問いをもう一度出し、最初の答えとの変化を見せる。
- 追加する問いの例:
  - リンを入れた n 型シリコンのかけらは、全体として＋に帯電している？ → いいえ。中性。
  - p 型シリコンの中の電子は、純粋なシリコンと比べてどうなる？ → 桁違いに少なくなる。
  - 空乏層の中に電子を置くとどうなる？ → 電場で n 側へ押し流される。
  - PN 接合で、空乏層の幅が広がるのはどんなとき？ → 逆バイアスをかけたとき、ドープが薄いとき。
  - ゲートに＋をかけたとき、表面に集まる電子はどこから来る？ → ソース(ゲートからではない)。
  - ピンチオフした後も電流が流れるのはなぜ？ → ピンチオフ点からドレインまでの強い電場が電子を運ぶから。
  - ゲートを何もつながずに放っておくとどうなる？ → 電荷が残ってオンのまま、またはふらつく。プルダウン抵抗が必要。
  - データシートの V_GS(th) を少し超える電圧で、MOSFET は十分にオンになる？ → ならない。R_DS(on) の測定条件を見る。

| PN 接合 | 階段接合・空乏近似(6 章の式) | 6, 7 |
| ダイオード | I = I_s(e^{V/V_T} − 1) | 7 |
| MOS | 1 次元・空乏近似(8 章の式) | 8, 9, 11 |
| MOSFET | 二乗則(V_th0 = 2.0 V、k = 0.1 A/V²)。12 章で λ とサブスレッショルドを追加 | 1, 9, 10 |
| 基板バイアス | V_th = V_th0 + γ(√(2φ_F + V_SB) − √(2φ_F))。γ と 2φ_F は 8 章のパラメータから計算した値にそろえる | 11 |
| 回路の過渡 | ゲート抵抗 R_G とゲート容量 C_iss の RC 充放電 + 二乗則。プルダウン抵抗、浮いたゲート(電荷保持 + 小さなノイズ) | 14 |

- **整合性**: 現行は γ = 0.5 V^½、2φ_F = 0.7 V を手で決めている。8 章のモデル(N_A、t_ox)から γ = √(2qε_Si·N_A)/C_ox と 2φ_F を計算し、同じ値になるように N_A と t_ox を選ぶ。選んだ N_A・t_ox を画面に明記する。
- **3D の粒の数は実際の濃度に比例しない**(実際は 1 µm³ に 10⁴ 個以上)。どの章でも「粒の数は見やすさのために減らしています。比率は保っています」と注記する。比率(n 側と p 側の濃度比など)はモデルどおりにする。

## 5. 正確さのチェックリスト(実装・レビュー時に確認)

- [ ] ドープした半導体を「帯電している」と表現していない。
- [ ] 空乏層を「キャリアがない層」だけで説明していない。必ず「イオンの電荷 → 電場」とセットにする。
- [ ] 電場の矢印は＋から−。電子は電場と逆向き、正孔は同じ向きに動く。
- [ ] 電流の向き(＋から−)と電子の流れる向きを両方示している。
- [ ] PN 接合と MOS で、両側の電荷の量が等しい(計器で確認できる)。
- [ ] 内蔵電位を「電池」として扱っていない。
- [ ] 反転層の電子の出どころをゲートと書いていない。
- [ ] ピンチオフを「電流が止まる」と書いていない。
- [ ] 模式図であること、粒の数を減らしていること、ボーア模型が簡略化であることを注記している。
- [ ] 表示する数値は、すべて 4 章の一覧のモデルから計算している(手書きの数字を置かない)。
- [ ] 少数キャリアを「少しいる」と曖昧に書いていない。桁(例: 10¹⁶ に対して 10⁴)で示している。
- [ ] 「ゲート電流は 0」は止まっているときの話であり、切り替える瞬間には充放電の電流が流れることを 14 章で明記している。
- [ ] データシートの例は架空の部品にしている(実在の型番の数値を使わない)。

## 6. 実装方針

- **ファイル構成**: 1 枚の HTML(現行 約 800 行)では 15 章を抱えきれない。章ごとのモジュールに分ける。
  ```
  apps/sims/mosfet/
  ├─ index.html          # 枠(レール、倍率の目盛り、パネル、計器)
  ├─ core/               # 物理モデル(純粋関数。単体テストを書く)
  │   ├─ constants.js  pn.js  mos.js  mosfet.js
  ├─ viz/                # 共通の表現(粒子、イオン、電場の矢印、試し電荷、3 段グラフ)
  └─ chapters/           # ch01-switch.js 〜 ch15-quiz.js
  ```
  Artifact として公開するときは `files` で複数ファイルを公開する(Three.js は CDN、ほかは同梱)。
- **物理モデルは表示から分離**し、`core/` の関数は Node で単体テストする(4 章の数値例、両側の電荷が等しいこと、V_th の式の整合性)。
- **電場の表示**: 断面の格子点で 1 次元(または 2 次元)の電場を計算し、InstancedMesh の矢印で描く。強さを長さと明るさに割り当てる。スマホでは矢印の数を減らす。
- **3 段グラフ**(電荷・電場・電位): 2D canvas。3D 断面と x 軸の位置・倍率をそろえる。
- **時間の再生**: 6 章の「くっつけた瞬間 → 釣り合い」は、シークバー付きの再生(再生 / 一時停止 / 巻き戻し)。
- **パフォーマンス**: スマホ(390 px 幅)で 30 fps 以上。粒は章ごとに最大 1,500 個程度。
- **アクセシビリティ**: 動きを減らす設定では揺れと再生アニメーションを止め、静止画と数値で同じ情報を伝える。
