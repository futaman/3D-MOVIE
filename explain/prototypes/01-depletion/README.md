# 解説ショートの試作 01: 空乏層の正体

MOSFET シミュレーター([futaman/MOSFET_SIM](https://github.com/futaman/MOSFET_SIM))の「PN 接合と電場」の章を縦型で録画し、タイトル帯と字幕を焼き込んだ 30 秒ほどのショート動画。
Explain モード仕様書([docs/EXPLAIN.md](../../../docs/EXPLAIN.md))の「台本 → 主張台帳 → 絵コンテ → 生成 → 字幕 → 書き出し」を、外部の有料 API を使わずに最小の形で通したもの。

| ファイル | 内容 |
|---|---|
| `storyboard.json` | タイトル、主張台帳(根拠つき)、ショット(字幕の文と、それを出すきっかけの出来事) |
| `record.cjs` | シミュレーターを 1600×900 で録画(操作パネルを隠し、空乏層を中心に 9:16 で切り抜く位置を記録)。出来事ごとに左上の印を白黒反転 |
| `build.mjs` | 動画の中の印から出来事の正確な時刻を求め、字幕(ASS)を作って ffmpeg で 1080×1920・30 fps の MP4 にする |

## 作り方

```bash
# MOSFET_SIM を横に clone しておく。Playwright と ffmpeg が必要
node record.cjs ../../../../mosfet_sim/index.html out
node build.mjs out          # → out/depletion.mp4
```

CDN に届かない環境では、3 つ目の引数に three.min.js(r128)のパスを渡す。

## 分かったこと

- 縦長の画面でシミュレーターを開くとカメラが遠ざかって主役が小さくなる。横長で録って切り抜くほうがよい。
- 描画の重い環境では、録画が時計より最大 3 秒ほど遅れる。字幕は時計ではなく、動画の中の印で合わせる必要がある。
- 粒の多い場面では、置いた電子が他の電子にまぎれやすい。試し電荷は色や大きさで目立たせる余地がある。
