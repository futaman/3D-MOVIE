# auto-short: ネタ落ち型の解説ショートを 1 本作る

作業場所は `explain/auto/`。1 本 = `episodes/<連番>-<英語の短い名前>/` に `episode.json`(台本、`"mode": "3d"`)と `visuals3d.js`(3D の場面)を書き、`node bin/run.mjs` で MP4 にする。見本は `episodes/01-paper-plane/`。**まず見本の 2 ファイルを読むこと。**(`visuals.js` と `lib/player.js` は旧 2D 方式。スライドに見えるので新しい回では使わない。)

## 手順

1. **テーマを決める**: 引数があればそれ。なければ、物理・数学・日常の素朴な疑問から 3 案出して 1 つ選ぶ。`episodes/` の既存の回と重ならないこと。他人の動画の題材・構成をなぞらない。
2. **台本 `episode.json` を書く**(下の「型」と「決まり」に従う)。
3. **計算を検証**: `node bin/verify.mjs episodes/<id>`。× が出たら、台本の数字のほうを計算値に合わせて直す(計算値を台本に合わせない)。
4. **外部の事実を確かめる**: `facts` の各項目を Web 検索で確かめ、出典を `source` に、確かめられたら `status: "confirmed"`。確かめられないものは台本から落とすか `unverified` のままにする(その場合アップロードは止まる)。仮定は `assumption` とし、字幕かフッターで仮定だと分かるようにする。
5. **場面 `visuals3d.js` を書く**: `window.WORLD = { init(g), update(sceneId, p, t, dur) }`。Three.js(r128、`g.T`)でローポリのセットを組み、固定キャラ「計算係」(見本の `makeChar` を流用)に実際に動作をさせ、カメラを動かす。`lib/player3d.js` の `g`(cam / label / screen / ease / out / seg / num / lerp)を使う。動きは (場面, p, t) だけで決める(`Math.random` と時計は使わない)。
6. **静止画で確認**: `node bin/tts.mjs episodes/<id> --silent && node bin/render.cjs episodes/<id> --qa-only` → `out/qa/*.png` を**全部 Read で見る**。下の QA の項目に 1 つでも当たれば直して再実行。`out/qa/report.json` の指摘も 0 件にする。
7. **本番**: `node bin/run.mjs episodes/<id>`(VOICEVOX が動いていれば音声つき、なければ自動で音声なしの下書き)。
8. **アップロード**(頼まれたとき、または定期実行のとき): `node bin/run.mjs episodes/<id> --upload`。非公開で上がる。公開は人が YouTube Studio で行う。未確認の事実があると止まるので、勝手に `--allow-unverified` を付けない。
9. 結果を報告: 題名、尺、検証の結果、未確認の事実、`final.mp4` の場所(とアップロード先の URL)。

## アセットの方針(重要)

人物・物・背景の形や動きを**コードで一から造形しない**。箱や球を組んでも、AI に造形スクリプトを書かせても「人形」止まりで、視聴に耐えない(第 1 回で検証済み。比較は `explain/auto/lab/shot01/compare.png`)。プロが作った既製の素材を選んで配置する。

- 人物: `assets/human01/`(MakeHuman の CC0 素材 + CMU のモーションキャプチャ)。`AutoAssets.loadCharacter("human01")`。作り方は同フォルダの README。
- 空・質感: `assets/env/`(Poly Haven、ambientCG。CC0)。足りないものは同じ配布元から取り、README の表に出典とライセンスを足す。
- 実在の場所の地形: `assets/hamanako/`(Sentinel-2 の色 + Copernicus DEM + ESA WorldCover。`AutoAssets.loadTerrain("hamanako")`)。ほかの場所も同じ `build_hamanako.py` の範囲を変えて作れる。出典は `episode.json` の `meta.credits` に入れる。
- 浜名湖まわりの構造物: `assets/hamanako_props/`(弁天島の赤鳥居、観覧車、ジェットコースター。`AutoAssets.loadModel("torii")` など)。柱と梁の構造物だけはスクリプトで実寸どおりに組んでよい。人物・生き物・彫刻・建物の外観は作らない。
- 地球: `assets/earth/`(NASA Blue Marble、パブリックドメイン)。地球の場面の見本は `episodes/02-gravity-tunnel/visuals3d.js`(断面図、`ll()` で緯度経度 → 球面)。
- クラウド環境では polyhaven.com などに直接つながらないことがある。その場合は npm レジストリ経由で、ライセンスが明記された素材だけを取る(例: `three-globe` の example に同梱の NASA 画像)。
- 画像テクスチャを読む回は `bin/render.cjs` が `--allow-file-access-from-files` 付きで Chromium を起動する(file:// の画像を WebGL に渡すため)。
- 使ってよいのは CC0 か、商用可で再配布可のものだけ。CC-BY は出典を記録。NC、再配布不可、ログインが必要な配布元(Mixamo、Sketchfab など)の素材はリポジトリに入れない。実在のロゴ・キャラクターは使わない。
- 描画は sRGB 出力 + ACES トーンマップ + 全天写真の環境光 + 影。見本は `lab/shot01/shot.js`。
- `episodes/01-paper-plane/visuals3d.js` と `assets/character/`(自作の人形)は旧方式。新しい回の見本にしない。

## 台本の型(ネタ落ち型)

場面は 9〜12 個、1 場面 1 文(長くて 2 文)、全体で 300〜380 字(45〜60 秒)。

1. **フック**: 真面目な問いを 1 文で。「大人げなく計算します」くらいの温度で入る。
2. **真面目な計算**(2〜3 場面): 実在の数値で検証し、普通の答えを出す。ここが笑いのフリなので手を抜かない。
3. **エスカレーション**(2〜4 場面): 「物足りないので」と非常識な仮定を段階的に持ち出す。計算はその仮定の下で真面目に続ける。仮定であることは隠さない。
4. **移動**: 仮定の結果、人や物が実際の地理の上を移動する(実在の経路・距離を計算する)。
5. **着地**: 計算の帰結として**浜名湖**(`landing`)に物理的にたどり着く。唐突につなげない。着地に必要な数字(距離など)から逆算して、エスカレーションの最後の仮定を決める。
6. **真顔の紹介**: 浜名湖の実用的な事実を 1〜2 個、淡々と(ここだけは毒を入れない)。
7. **コールバック**: 途中で出た数字を回収して「〜ではなく、〜でどうぞ」で締める。

## 決まり

- 語り口は真面目な解説がベース。そこに理系オタク的な、シニカルでトゲのある一言を場面ごとに足す(例:「人体の耐久性は、今回は考えません」「物理は、距離に興味がありません」「リニアと同じで、電気代はゼロです」)。毒は物理・仮定・状況・自分たちに向け、実在の人・企業・地域を貶さない。一言にも数字が出るなら `checks` か `facts` に入れる。
- 字幕はナレーションを句読点で自動分割して白 1 行で出る。読点なしで 15 字を超える部分を作らない(`caption` は 3D では使わない)。
- 台本に出る数値はすべて `checks`(コードで再計算できるもの)か `facts`(出典つき)のどちらかに入れる。地理の距離は `places` の緯度経度から `dist()` / `xtrack()` / `along()` で計算する。
- 浜名湖の観光情報(日程・料金・営業など変わりうるもの)は、検索で確かめた当日の出典がない限り書かない。
- 絵は 2D の図解。実在の企業ロゴ・キャラクター・人物を描かない。縮尺を変えた図には「模式図」「高さは横より大きく描いています」などと書く。
- 画面の文字は最小限: タイトル帯・注記・箇条書きは出さない。数字は場面の中のラベル(`g.label` は物に付く、`g.screen` は画面固定)で 1 場面 1〜2 個まで。字幕は y=668 付近なのでラベルは y 630〜705 を避ける。

## QA(静止画で 1 つでも当たれば直す)

- 文字が切れている・重なっている・読めないほど小さい(14px 未満)
- 「動くスライド」に見える(キャラも物も動かない、カメラが止まったまま、主役が小さい・画面の外)
- ラベルの数字がナレーションと食い違っている、単位がない、色が白飛びしている
- 何の絵か 1 秒で分からない場面がある、動きのない場面が 3 秒以上続く
- 仮定なのに事実のように見える表現がある

## 環境

- Node 20 以上、ffmpeg、`npm install`(Playwright)と `npx playwright install chromium` を `explain/auto/` で 1 回。
- VOICEVOX を起動しておく(`http://127.0.0.1:50021`)。話者は `episode.json` の `voice.speaker`(既定 13)。使う話者の利用規約とクレジット表記を確認し、説明文に入れる。
- アップロードは `explain/auto/README.md` の手順で 1 回だけ認可する。
